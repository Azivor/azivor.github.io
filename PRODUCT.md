# Azivor
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
Repository-defined audience: students exploring modern AI; parents are a secondary audience for the learning approach. No audience change is requested in this redesign.
## Product Purpose
A student-led project connecting AI possibilities to concrete work students can make, understand, and check.
## Capabilities and Constraints
Existing static Node-generated site hosted on GitHub Pages. Home, Explore, Builds, About, a component reference, and an Earth scene study. Native links and readable content must work without JavaScript. Keep existing fragment destinations usable.
## Brand Commitments
Azivor name and paper-airplane mark. The user's current request replaces repetitive placement and excessive front-facing text; it says the existing visual design looks nice. Preserve the recognizable Earth/blue identity while replacing content composition.
## Evidence on Hand
The actual WebGL Earth descent, its browser capture, and its recorded revision. An authored revision exercise and developing Human Loop framework. No validated educational results or additional published project evidence.
## Product Principles
Lead with inspectable work. Let visitors choose depth. Keep student judgment visible. Do not fabricate projects, adoption, or outcomes.
## Open Decisions
The user chose an editorial magazine with varied layouts and stronger storytelling, and direct implementation of the working pages.
